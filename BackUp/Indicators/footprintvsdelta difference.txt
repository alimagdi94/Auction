## 7. Structural Verdict

AuctionDelta is **derived from the same codebase** as Footprint:

- All core infrastructure is shared: `InsertBar`, `GetBar`, `ProcessTicks`, `LoadHistory`, `ReloadHistory`, `SortLevels`, `FindPOC`, `FindVA`, `Classify`, `AccumulateTick`, `DrawPanel`, `LayoutPanel`, `Render`, `OnInit`, `OnCalculate`, `OnChartEvent`
- The **only intentional differences** are:
  1. **Cell color model** — Footprint uses separate bid/ask heatmap colors; AuctionDelta uses a single unified green gradient
  2. **Input naming convention** — `InpBidBaseColor` etc. → `InpClrCellLo` etc.
  3. **Bar struct renamed** — `FPBar` → `AuctionBar`
  4. **Signal function renamed** — `ComputeBarSignals` → `ComputeSignals`
  5. **Absorption threshold** — configurable in FP, hardcoded in AD
  6. **DrawBar** — FP is 313L (handles bid/ask column split colors separately); AD is 204L (unified color simplifies the loop)
  7. **Panel** — FP has more buttons (ChartMode, WickColor); AD is trimmed

Everything else — tick processing, bar management, imbalance logic, VA, POC, stacked imbalances, unfinished auction, canvas infrastructure — is **identical**.
