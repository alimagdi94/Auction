Pass 1 — RESTART-WIPE (High)
g_dayStartDay added to RiskStateSave() and RiskStateLoad(). On same-day restarts, CheckNewDay() now sees dt.day == restored_day and returns early, preserving the halted session state that RiskStateLoad() just recovered. On genuine day rollovers it correctly fires the reset.
Pass 2 — DEAD-UA (Low)
Unfinished Auction block fixed in two ways: (1) spatial targets swapped to match ascending sort — is_unfinished_lo now goes to levels[0] (bar LOW), is_unfinished_hi to levels[len-1] (bar HIGH); (2) condition replaced with the standard near-zero aggressor-side check using InpExhaustionZeroRat as the threshold, matching how exhaustion is detected elsewhere.
Pass 3 — CARRY-SCAN (Medium)
ComputeHFTSignal() gets an optional preOFS = -1 parameter. Both PlaceOrders() and EvalAndFireSignal() now call ComputeOFScore(bi) once, store the result, and pass it through — eliminating the internal redundant call inside ComputeHFTSignal. The explicit duplicate call in PlaceOrders is removed. Level scan count per bar close drops from 4 to 2.
Pass 4 — CARRY-POC (Medium)
ComputeNakedPOCs() replaced with an O(n log n) implementation. Two helper functions added: SortPocPartition() (parallel-array Lomuto quicksort on price+barIdx) and NpocBinLo/Hi() (binary search for range bounds). The algorithm collects POC prices, sorts them by price, then does a single forward bar pass using binary search to mark retested POCs in one pass — reducing 12.5 million comparisons at 5,000 bars to roughly 60,000.
Pass 5 — CARRY-CVD (Low)
C6 in ComputeHFTSignal and Component 4 in GetConvictionResult now use the recency-weighted 3-bar formula (2*(nd0-nd1) + (nd1-nd2)) / 3. This reads bi-1 explicitly and weights the most recent delta change twice as heavily as the older segment, making sharp reversals at bi-1 visible to the slope calculation rather than cancelling out.
