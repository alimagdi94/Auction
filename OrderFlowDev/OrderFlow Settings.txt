Here are four concrete signal profiles, each tuned for a specific execution style. The edge comes from *which components dominate* at each frequency, not just lowering the threshold blindly.

---

## How the score threshold maps to selectivity

The HFT score is a weighted composite of 6 independent order-flow factors (OFS, delta divergence, POC position, absorption, exhaustion, CVD slope). At **threshold 60** roughly 1-in-8 bars fires. At **45** roughly 1-in-3. The frequency gate (`InpSignalFreqBars`) prevents stacking within a cluster.

The edge isn't in the threshold alone — it's in keeping the *supporting inputs tight enough* that the component scores mean something.

---

## Profile 1 — Pure Scalp (M1 / M2)
*Highest frequency, smallest stop, needs fast delta confirmation*

```
InpTickSize           = 1          // single-point cells — full granularity
InpTickMultiplier     = 1          // no aggregation
InpImbalanceRatio     = 200.0      // looser — catch early imbalances before they mature
InpStackedImbCount    = 2          // only 2 consecutive needed (fast market)
InpAbsorptionRatio    = 3.0        // more sensitive absorption detection
InpExhaustionCells    = 2          // 2 near-zero cells is enough at M1
InpExhaustionZeroRat  = 0.08       // slightly wider zero band on fast flow
InpSignalThreshold    = 45         // lower bar — fires on moderate confluence
InpSignalFreqBars     = 1          // every bar is eligible
```

**Edge:** At M1, delta divergence (component 2, 20% weight) is the strongest single edge because it reveals trapped participants in real time. The lower absorption ratio ensures you see the absorption before it's obvious. Threshold 45 means three strong components firing is enough — you don't need all six to agree.

## Profile 2 — High-Frequency Day Trade (M5)
*Best balance of frequency and signal quality, most tested by practitioners*

```
InpTickSize           = 5
InpTickMultiplier     = 2
InpImbalanceRatio     = 250.0
InpStackedImbCount    = 2
InpAbsorptionRatio    = 3.5
InpExhaustionCells    = 2
InpExhaustionZeroRat  = 0.06
InpSignalThreshold    = 52         // just above neutral — requires lean
InpSignalFreqBars     = 2          // skip one bar minimum
```

**Edge:** At M5 the CVD momentum slope (component 6) becomes meaningful — three completed M5 bars gives you roughly 15 minutes of directional flow momentum. POC gravity (component 3) is also reliable at this granularity because institutional prints have time to cluster at a single level. Threshold 52 means the composite just needs to show directional lean, which cuts out the genuinely flat bars while catching early-trend entries.

## Profile 3 — Flow Momentum (M15 / M30)
*Lower frequency, higher conviction per signal, holds longer*

```
InpTickSize           = 10
InpTickMultiplier     = 5
InpImbalanceRatio     = 300.0      // standard — only clean stacks
InpStackedImbCount    = 3          // full three-stack required
InpAbsorptionRatio    = 4.5        // only heavyweight absorption counts
InpExhaustionCells    = 3          // three-cell exhaustion — strong signal
InpExhaustionZeroRat  = 0.05
InpSignalThreshold    = 62         // requires genuine confluence
InpSignalFreqBars     = 4          // one signal per ~1 hour at M15
```

**Edge:** At M15+ the stacked imbalance (component 1 via OFS) and absorption at extremes (component 4) dominate. A 3-stack imbalance at M15 represents a genuine institutional order cluster that the market usually needs to return to. The higher absorption ratio ensures you're only flagging levels where a meaningful delta fight occurred.

## Profile 4 — Aggressive Reversal Hunt (any timeframe)
*Specifically targets delta divergence + exhaustion confluence — the highest-edge setup in order flow*

```
InpImbalanceRatio     = 350.0      // only extreme imbalances qualify
InpStackedImbCount    = 3
InpAbsorptionRatio    = 5.0        // very high bar — only clear absorption
InpExhaustionCells    = 3
InpExhaustionZeroRat  = 0.04       // very strict near-zero definition
InpOFWtDelta          = 30.0       // keep as-is
InpSignalThreshold    = 65         // high bar — needs 4-5 components agreeing
InpSignalFreqBars     = 5          // wait for clear setups
```

**Edge:** This profile only fires when delta divergence AND exhaustion AND absorption all point the same direction. Historically in order flow this three-way confluence has the strongest win-rate on reversals because it means: (a) price moved in one direction but real delta disagreed, (b) the aggressive side ran dry at the extreme, and (c) a large passive player absorbed the final push. That combination identifies failed auctions — the most reliable footprint signal.

---

## One universal rule on frequency vs edge

The right balance isn't "fire as often as possible." It's fire often enough that you're never waiting more than 2-3 average bars for a setup, but selective enough that when it fires, the structure is genuinely asymmetric. For most traders that sweet spot is **Profile 2 with threshold 50-55 on M5**, adjusted to 58-62 once you've verified the signals align with your session's typical range and volatility.
